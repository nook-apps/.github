# Приложения для Linux

Приложения с открытым исходным кодом. Shelf и Jot делаем под Hyprland,
Pick работает в терминале.

<br>

## <img src="https://raw.githubusercontent.com/nook-apps/.github/main/profile/assets/shelf.svg" width="40" height="40" alt="Иконка Shelf"> Shelf

Файловый менеджер для Hyprland. Вкладки, быстрый просмотр по пробелу,
архивы и отправка файлов через LocalSend. Стекло и цвета подстраиваются под рабочий стол.

**[Скачать Shelf](https://github.com/nook-apps/shelf/releases/latest)**
&nbsp; · &nbsp;
[Установка и возможности](https://github.com/nook-apps/shelf#readme)

<br>

## <img src="https://raw.githubusercontent.com/nook-apps/.github/main/profile/assets/jot.svg" width="40" height="40" alt="Иконка Jot"> Jot

Markdown-редактор для Hyprland. Разметка проявляется на строке с курсором,
а файл остаётся обычным текстом. Автосохранение, вкладки и папка с заметками.

В разработке. Пока доступна сборка из исходников.

**[Собрать Jot](https://github.com/nook-apps/Jot#readme)**

<br>

## <img src="https://raw.githubusercontent.com/nook-apps/.github/main/profile/assets/pick.svg" width="40" height="40" alt="Иконка Pick"> Pick

Центр приложений в терминале. Разрабатываем поиск и установку программ
из разных репозиториев в одном интерфейсе.

Прототип: интерфейс работает на демонстрационных данных, установка ещё не подключена.

**[Посмотреть Pick](https://github.com/nook-apps/Pick#readme)**

<br>

## Для разработчиков

[Общий модуль Nook](https://github.com/nook-apps/glaze) на Qt 6 / QML:
тема, стекло, кнопки, диалоги и интеграция с системой. Уже используется в Jot.

Нашли ошибку или хотите предложить изменение? Откройте issue в репозитории приложения.
