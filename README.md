# Nook organization profile

`profile/README.md` — публичная витрина организации [nook-apps](https://github.com/nook-apps).
GitHub показывает её на вкладке Overview из основной ветки публичного репозитория `.github`.

В `profile/assets/` лежат оригинальные иконки приложений и два варианта SVG-баннера
для светлой и тёмной темы GitHub. Баннеры используют контуры букв, поэтому не зависят
от установленных у посетителя шрифтов. Анимации, внешние шрифты и сервисы бейджей не нужны.

Ссылки на assets абсолютные: относительные адреса на странице организации могут
разрешаться иначе, чем в репозитории. При переносе репозитория или переименовании
основной ветки нужно обновить URL в `profile/README.md`.

Статус приложений проверен по их публичным README. Перед изменением описаний
сверяйте возможности и доступность пакетов с репозиториями приложений.

## Графика

Оригинальные иконки скопированы без изменений из [Shelf](https://github.com/nook-apps/shelf),
[Jot](https://github.com/nook-apps/Jot) и [Pick](https://github.com/nook-apps/Pick).
В баннерах использованы те же иконки. Для графики Shelf и Jot сохранены условия
GPL-3.0-or-later; текст лицензии — в `licenses/GPL-3.0.txt`.
Надпись Nook переведена в контуры из DejaVu Sans Bold; лицензия шрифта —
в `licenses/DejaVu.txt`.
